# Higercoin Terminal Pro

A browser-based Bitcoin portfolio tracker with AI-assisted analysis. The interface is in Turkish.

## Features

- Track a Bitcoin portfolio
- AI-based analysis of holdings and market data

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Higer23/higercoin.git
   cd higercoin
   ```
2. Open `index.html` in a modern browser.
